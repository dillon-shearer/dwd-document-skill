# DWD

Document branding skill for Data With Dillon (DWD): rules and templates any AI agent can read to produce on-brand Word, PowerPoint and other documents. It follows the open Agent Skills format, with `SKILL.md` at the root, rules under `references/` and templates under `assets/`. GitHub: https://github.com/dillon-shearer/dwd-document-skill

## How to check

Run `python check.py` from the repo root. It exits 0 when every check passes or is skipped.
