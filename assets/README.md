# Assets

Templates (docx, pptx, xlsx) land here. They are built by the scripts under `scripts/`, so change the script and rebuild rather than editing a template by hand.

`dwd-sample.md` is the Markdown sample. It is written by hand, not built by a script, and it is the fixture `scripts/check_md.py` must pass. `dwd-report.html` is the HTML template and sample in one file. It is written by hand, not built by a script, and it is the fixture `scripts/check_html.py` must pass; its `<style>` block is the reference stylesheet every HTML deliverable must start with.
